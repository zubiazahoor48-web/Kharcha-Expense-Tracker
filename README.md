Kharcha – Expense Tracker

A simple, responsive expense tracker that runs entirely in the browser. Add income and expenses, filter them, see where your money goes, and export everything to CSV. No backend or build step needed.

Features:
Add, edit and delete transactions (income or expense)
Live summary of balance, income and expenses
Spending-by-category doughnut chart (Chart.js)
Search by description, filter by type and month
Form validation with clear error messages
Export the current view to CSV
Data saved in the browser with localStorage
"Load sample data" button for a quick demo
Responsive layout, keyboard-friendly, respects reduced motion

Tech stack:
HTML5
JavaScript (ES6+, no framework)
Bootstrap 5 for components (navbar, modal, table, forms, toast)
Tailwind CSS (CDN) for layout and spacing utilities, with preflight disabled so it does not conflict with Bootstrap
Chart.js for the chart
